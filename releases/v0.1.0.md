# Puzzle Book v0.1.0

**Released:** 2026-07-22
**Build:** 0.1.0+1
**Source commit:** `f09fad7` (also tagged `v0.1.0`)

First distributable release of the Puzzle Book app — three puzzle modules, each with
an interactive tutorial and full RU/EN/DE localization.

## Modules included

| # | Module | Status |
|---|--------|--------|
| 01 | Rebus (picture rebuses) | complete, 15-step tutorial |
| 02 | Digit Rebus (4×4 equation grid) | complete, 9-step tutorial |
| 03 | Domino Solitaire (chain placement) | complete, tutorial |
| 04 | Labyrinth (alphabet path) | complete, 12-step tutorial |

All three share one shell, save files, audio, and home screen.

## Install

**Android** — sideload the APK. minSdk 24 (Android 7.0+). Debug-signed (not store-ready).
Tested on Meizu M6 Note (LineageOS, Android 11).

**Windows x64** — unzip and run `puzzles.exe`. No installer.
