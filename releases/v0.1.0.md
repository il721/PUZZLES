# Puzzle Book v0.1.0

**Released:** 2026-09-22
**Build:** 0.1.0+1
**Source commit:** `53a47d4` (also tagged `v0.1.0`)

First distributable release of the Puzzle Book app — six puzzle modules with full RU/EN/DE localization — five with an interactive
tutorial, plus a playground of seven standalone mini-games.

## Modules included

| # | Module | Status |
|---|--------|--------|
| 01 | Rebus (picture rebuses) | complete, 15-step tutorial |
| 02 | Digit Rebus (4×4 equation grid) | complete, 9-step tutorial |
| 03 | Domino Solitaire (chain placement) | complete, tutorial |
| 04 | Labyrinth (alphabet path) | complete, 12-step tutorial |
| 05 | Squareword (letter-square grid) | complete, tutorial |
| 06 | Playground (seven mini-games) | complete, per-game rules sheet |

All six share one shell, save files, audio, and home screen.

## Install

**Android** — sideload the APK. minSdk 24 (Android 7.0+). Debug-signed (not store-ready).
Tested on Meizu M6 Note (LineageOS, Android 11).

**Windows x64** — unzip and run `puzzles.exe`. No installer.
